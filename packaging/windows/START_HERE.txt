SPIRAL OS: HAKUI ENGINE
WINDOWS STARTUP PACK // v0.83 POP THEN FLICK CORRECTION

Run:
SPIRAL-OS-HAKUI-ENGINE.exe

KEYBOARD + MOUSE:
WASD        MOVE
MOUSE       CAMERA INPUT
RMB + MOUSE ORBIT CAMERA
WHEEL       ZOOM CAMERA
SPACE       JUMP
LEFT SHIFT  SPRINT
E           INTERACT / USE / SIT / STAND
Q           GUARD / CONTEXTUAL MODIFIER
F           CONTEXT / GRIND
LEFT CTRL   BALANCE / MANUAL
C           CANCEL / DISMOUNT / ENTER OR LEAVE SPAR
R           RECOVER / CAMERA RESET
ESC         PAUSE / RESUME
F10         QUIT
F12         CAPTURE READ-ONLY EXPERT SNAPSHOT

GAMEPAD (SDL-COMPATIBLE):
LEFT STICK  MOVE / STEER
RIGHT STICK CAMERA; FIRST DECISIVE AIR FLICK AFTER A SUCCESSFUL RIDE POP
SOUTH       JUMP ON FOOT; IMMEDIATE OLLIE / BUNNY HOP WHILE RIDING
EAST        CANCEL / DISMOUNT
WEST        INTERACT / PRIMARY ACTION / RIDE STYLE
NORTH       SECONDARY ACTION / RIDE GRIND
LB / RB     RIDE BODY SPIN LEFT / RIGHT
LT          GUARD / RIDE BALANCE
RT          ACCELERATE / RIDE PROPULSION
START       PAUSE / RESUME
R3          RESET CAMERA
DPAD UP     ON FOOT
DPAD LEFT   SKATEBOARD
DPAD RIGHT  BMX

RIDE TRICK RHYTHM:
SOUTH       POP IMMEDIATELY
RELEASE     SOUTH MAY BE RELEASED IMMEDIATELY
THEN RS     FLICK ONCE DURING THE SHORT AIRBORNE TRICK WINDOW
NO FLICK    NORMAL OLLIE / BUNNY HOP ONLY
LATE RS     CAMERA INPUT; NOT AN ACCIDENTAL TRICK

CONTROLLER FAMILY PROMPTS:
PLAYSTATION CROSS/CIRCLE/SQUARE/TRIANGLE + L1/R1/L2/R2
XBOX        A/B/X/Y + LB/RB/LT/RT
GENERIC SDL SOUTH/EAST/WEST/NORTH + SEMANTIC SHOULDER/TRIGGER LABELS

RIDE INPUT POLICY:
Advanced skateboard and BMX activation requires a connected SDL gamepad.
If none is available HAKUI displays:
RIDE INPUT UNAVAILABLE // CONNECT GAMEPAD TO SYNCHRONIZE

Developer-only keyboard ride fallback:
F9          TOGGLE FALLBACK
1           ON FOOT
2           SKATEBOARD
3           BMX
4           CAR (DEFERRED / IMMOBILE)
Z / X       PRIMARY / SECONDARY RIDE OR COMBAT ACTION
V           LEGACY GUARD
M           LEGACY MANUAL

FUSION TABLE (ONLY WHILE SEATED):
E / WEST    DISPLAYED CONTEXT ACTION (OPEN / BET / HIT / STAND)
C / EAST    LEAVE TABLE

EXPERT OBSERVER:
F12 writes a timestamped HAKUI-OBSERVE bundle beside the executable.
The bundle is read-only diagnostic output and does not control gameplay.

SETTINGS:
[ / ]       LOOK SENSITIVITY
- / +       AUDIO VOLUME

HAKUI uses semantic actions internally. Prompts change to the most recently
active device, and controllers may connect or disconnect while the game runs.
Virtual credits only. No purchase or cash-out.
