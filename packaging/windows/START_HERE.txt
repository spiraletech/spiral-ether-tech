RIDE INPUT POLICY:
Advanced skateboard and BMX activation requires a connected SDL gamepad.
If none is available HAKUI displays:
RIDE INPUT UNAVAILABLE // CONNECT GAMEPAD TO SYNCHRONIZE

Developer-only keyboard ride fallback:
F9          TOGGLE FALLBACK
1           ON FOOT
2           SKATEBOARD
3           BMX
4           CAR (DEFERRED / IMMOBILE)
Z / X       PRIMARY / SECONDARY RIDE OR COMBAT ACTION
V           LEGACY GUARD
M           LEGACY MANUAL

FUSION TABLE (ONLY WHILE SEATED):
E / WEST    DISPLAYED CONTEXT ACTION (OPEN / BET / HIT / STAND)
C / EAST    LEAVE TABLE

EXPERT OBSERVER:
F12 writes a timestamped HAKUI-OBSERVE bundle beside the executable.
The bundle is read-only diagnostic output and does not control gameplay.

SETTINGS:
[ / ]       LOOK SENSITIVITY
- / +       AUDIO VOLUME

HAKUI uses semantic actions internally. Prompts change to the most recently
active device, and controllers may connect or disconnect while the game runs.
Virtual credits only. No purchase or cash-out.
